## HR Analytics & Workforce Performance Dashboard
📌 Project Overview
A comprehensive end-to-end data analytics project designed to evaluate workforce performance, monitor employee attrition patterns, and analyze salary distribution and demographics across departments using Power BI.

🛠️ Key Phases & Workflow
Data Preparation & ETL (Power Query):

Cleaned and transformed raw workforce datasets.

Structured columns, handled data types, and ensured data integrity for downstream analysis.

Data Modeling & DAX Measures:

Developed advanced calculated measures (DAX) to track core HR metrics, including:

Average Tenure: Tracking average employee loyalty and length of service.

Attrition Rate: Measuring employee turnover percentages.

Avg Salary Per Hour: Evaluating compensation benchmarks.

Interactive Visual Dashboards:

Built a dynamic, executive-level dashboard (Executive Summary) featuring headcount distribution, marital status breakdowns, department performance matrices, and interactive slicers for deep-dive analysis.

📊 Key Insights & Metrics
Total Workforce: Monitored over 1,400 active and historical employee records.

Department Breakdown: Highlighted headcount concentration and attrition trends primarily within Research & Development and Sales sectors.

Compensation Analysis: Evaluated hourly rates and average tenure to support data-driven retention strategies.

🚀 Technologies Used
Power BI (Interactive Dashboards & Data Visualization)

Power Query (Data Transformation & ETL)

DAX (Data Analysis Expressions) (Calculated Measures)
